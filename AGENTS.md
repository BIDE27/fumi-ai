## 2. LE TRIPTYQUE ARCHITECTURAL DU PROJET : CE QUE NOUS CONSTRUISONS

Le dépôt `fumi-ai` est conçu comme une plateforme modulaire complète composée de 3 piliers :

```
┌─────────────────────────────────────────────────────────────────────────────────┐
│                           L'ÉCOSYSTÈME GLOBAL FUMI AI                           │
├───────────────────────────────┬─────────────────────────────────────────────────┤
│ 1. SITE WEB NEXT.JS 15        │ • Interface Chat miroir de Fa & Vodun Connect   │
│    (Dossier: src/)            │ • Portail Développeur de gestion des Clés API   │
│                               │ • Console de test interactive en direct         │
├───────────────────────────────┼─────────────────────────────────────────────────┤
│ 2. APPLICATION REACT NATIVE   │ • Application mobile iOS & Android (Expo)       │
│    (Dossier: mobile-app/)     │ • Expérience tactile fluide, bulles & voix      │
│                               │ • Suggestions proactives du Fêzan & du Fâ       │
├───────────────────────────────┼─────────────────────────────────────────────────┤
│ 3. API GATEWAY SOUVERAINE     │ • Route /api/v1/chat/completions (OpenAI SDK)   │
│    (Compatible OpenAI)        │ • Authentification Bearer (fumi_sk_live_...)    │
│                               │ • Moteur RAG & Distillation hybride             │
└───────────────────────────────┴─────────────────────────────────────────────────┘
```

### A. Le Site Web Next.js 15 & Portail Développeur
- **Localisation** : `src/app/`
- **Interface de Chat (`page.tsx`)** : Reprend textuellement l'interface d'élite de Fumi de *Fa & Vodun Connect* : tiroir mobile latéral, gestion multi-sessions, sélecteur de mode de réflexion (*Rapide*, *Adaptatif*, *Réflexion profonde*), pièces jointes images, formules KaTeX, schémas SVG, boutons d'action et voix.
- **Portail Développeur (`/keys`)** : Permet aux développeurs et clients de :
  - Générer de nouvelles clés d'API sécurisées (`fumi_sk_live_...`).
  - Consulter la documentation d'intégration cURL, Python et TypeScript.
  - Tester leurs requêtes en direct dans une console de test connectée à l'API.

### B. L'Application Mobile React Native (iOS & Android)
- **Localisation** : `mobile-app/`
- **Framework** : React Native avec Expo, `react-native-safe-area-context` et `lucide-react-native`.
- **Rôle** : Offrir aux utilisateurs une application mobile dédiée, installable sur leur smartphone pour converser avec Fumi à tout instant.
- **Conformité tactile** : Cibles tactiles d'au moins 44x44px, police minimale de 16px sur les champs de saisie pour empêcher le zoom intempestif iOS Safari/WebKit.

### C. L'API Gateway Souveraine (Compatible OpenAI)
- **Localisation** : `src/app/api/v1/chat/completions/route.ts`
- **Spécification** : 100% conforme à l'API standard d'OpenAI. Tout client officiel (`openai.OpenAI(...)` en Python, Node, Flutter ou cURL) peut appeler Fumi en changeant uniquement `base_url` et `api_key`.
- **Authentification** : Gérée de façon Zero-Trust par `src/lib/apiKeyAuth.ts`.

## 6. RÈGLES FONDAMENTALES D'INGÉNIERIE POUR LES AGENTS ANTIGRAVITY

### Règle 1 : Conception « Mobile-First » Systématique
1. **Écrans étroits (320px à 414px) en priorité absolue** : Tout composant développé doit être parfait sur iPhone SE / Android compact avant d'être adapté sur desktop.
2. **Zéro Débordement Horizontal** :
   - Toujours appliquer `min-w-0` sur les enfants flexibles (`flex-1 min-w-0`).
   - Assurer un scroll horizontal fluide (`overflow-x-auto`) sur les blocs de code et formules mathématiques.
3. **Cibles Tactiles Conformes** : Boutons et icônes d'au moins 44x44px.

### Règle 2 : Sécurité Maximale & Architecture Zero-Trust
1. **Validation stricte côté serveur** : Aucune donnée client n'est considérée fiable sans vérification.
2. **Vérification des clés API** : Toute requête sur `/api/v1/...` doit valider le jeton Bearer `fumi_sk_...` via `src/lib/apiKeyAuth.ts`.
3. **Protection des clés secrètes** : Ne jamais exposer `GEMINI_API_KEY` ou `GROQ_API_KEY` côté client.

### Règle 3 : Compatibilité Universelle iOS Safari WebKit & Android
1. **Taille de police minimale 16px sur les champs de saisie** : Tout `<input>` ou `<textarea>` doit avoir `text-base` ou `text-[16px]` pour bannir le zoom automatique intempestif d'iOS Safari.
2. **Dates ISO** : Ne jamais instancier `new Date("YYYY-MM-DD HH:mm:ss")` sous peine de crash Safari (`Invalid Date`). Utiliser le format ISO (`YYYY-MM-DDTHH:mm:ssZ`).
3. **Préfixes CSS** : Doubler systématiquement `backdrop-filter` avec `-webkit-backdrop-filter`.

### Règle 4 : Règle de Langue pour les Commits Git (Français Obligatoire)
Tous les messages de commit git (`git commit`) doivent impérativement être rédigés en **français**, en suivant le standard *Conventional Commits* :
- `feat(chat): amélioration du rendu des cartes SVG`
- `fix(keys): correction de la copie de clé API sur mobile`
- `docs(agents): mise à jour des directives de distillation`

### Règle 5 : TypeScript Strict & 0 Erreur de Compilation
Avant chaque livraison ou conclusion de tâche, vous devez obligatoirement exécuter :
```bash
npm run typecheck
```
Le typage TypeScript doit compiler avec **strictement 0 erreur**.
